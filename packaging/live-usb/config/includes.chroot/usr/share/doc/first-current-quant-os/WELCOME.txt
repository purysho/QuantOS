First Current Quant OS — free, open-source investment research (Apache-2.0)
==========================================================================

What it does
  Point-in-time research: SEC fundamentals, Treasury rates, ECB FX, FRED macro,
  NBER/Fed/BIS/ECB working papers, and (with a free personal key) stock prices,
  shown in a read-only analytical terminal. It never places trades.

Setup asks for
  1. A contact email. SEC EDGAR and Crossref require one in every request.
     It is sent only to those public data sources.
  2. Tickers you want to research (optional; add more later with `quantos setup`).
  3. Optional free personal API keys (press Enter to skip):
       TIINGO_API_KEY  stock prices    https://www.tiingo.com
       FRED_API_KEY    macro vintages  https://fredaccount.stlouisfed.org
     Keys are stored in ~/FirstCurrent/secrets (readable only by you).

Everyday use
  quantos daily            fetch new data and refresh the terminal
  quantos doctor --online  check that everything works
  Terminal                 http://127.0.0.1:8765/  (desktop icon)

Persistence
  If you created the USB with `make-first-current-usb`, your home folder lives
  on an encrypted partition and survives reboots. Without it, everything is
  lost at shutdown.
